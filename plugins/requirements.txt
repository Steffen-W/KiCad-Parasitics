# The numeric stack is constrained by bfieldtools 0.11.3, which is unmaintained
# and only works with older scipy/numpy:
#   * scipy >= 1.15 removed scipy.special.lpmn, which bfieldtools imports, so a
#     newer scipy breaks "import bfieldtools" with an ImportError.
#   * scipy 1.13.x in turn pins numpy < 2.3 itself, so numpy needs no extra cap.
# Verified working: numpy 2.2.6 + scipy 1.13.1. Do not raise the scipy ceiling
# without checking that "import bfieldtools" still succeeds.
bfieldtools>=0.11.3
scipy>=1.13.1,<1.15
numpy>=2.2.6

# These track recent releases; floors are the tested minimums.
kicad-python>=0.5.0
matplotlib>=3.8
wxPython>=4.2
trimesh>=4.0

# 50x faster trimesh cache hashing; otherwise it falls back to slow hashlib
# (see the "falling back to hashlib hashing" log line).
xxhash
